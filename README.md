# 01 – Profile Details App (React JS)

A mobile-style "My Profile" screen built with React + Vite.

## Features
- Black app bar titled **My Profile**
- Circular avatar with a green verified tick
- Name, Email (with mail icon) and Points (with star icon)
- Floating **+** button that increases the points

## Run locally
```bash
npm install
npm run dev
```
Open the URL shown in the terminal (usually http://localhost:5173).

## Build
```bash
npm run build
```

## Edit profile data
Change the `useState` values at the top of `src/App.jsx`.
